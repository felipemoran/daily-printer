# PullRequestTemplate

Review queue for pull requests: two-line display title, a count line, then one block per PR with number, age tag (solid STALE when over 2 days), title, area and DiffGlyph.

- Feed it: PRs waiting on you, oldest first, with additions/deletions and age.
- For a single PR event (merged, changes requested), use TicketTemplate with the PR number as the ID.
