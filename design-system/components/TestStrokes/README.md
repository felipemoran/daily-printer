# TestStrokes

Paper test for the stroke scale under erosion (item 8 of the To verify list). Print, then compare the measured thickness of each rule to its label.

- Erosion trims the bottom dot of vertical black runs of 3+ dots, so a horizontal rule of N ≥ 3 px may print as N − 1. Vertical lines lose only one dot at the bottom end.
- Rows: horizontal solid rules 2–9px, the 2px and 4px dashed rules, vertical bars of the same widths, box outlines at 2/3/4/6px, and the current scale (2/3/4/6/8) beside an alternative (2/4/6/9).
- Look for: whether 3px solid reads thicker than 2px dashed; whether 2/3/4 are three distinct steps; whether box outlines look even on all four sides.
