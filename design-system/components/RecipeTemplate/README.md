# RecipeTemplate

A recipe to cook from: HeaderBar with yield and time → display title → Leaders for the essentials → ingredient checklist (TaskRow without meta clutter) → numbered Steps with timer chips → NoteLines for tweaks → TearLine stub.

- Feed it: name, servings, total time, ingredients with quantities, steps with optional timers.
- Quantities go in the ingredient title (`300 g arborio`), never inside steps. Intentional template: recipes are a stated use.
