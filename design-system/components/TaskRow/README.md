# TaskRow

A to-do line built for a pen: a hollow 4px checkbox to tick by hand, a bold title, a metadata line and an optional reversed tag. Done items print with a solid ✓ box and a 3px strike-through.

- Provide: `title`, `meta`, `done`, `tag` (`"P1"`, a due date).
- Rows are separated by 2px dashed rules. List open items first, done items last.
- Use for tasks, shopping and ingredient lists, review queues.
