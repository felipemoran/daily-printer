# Rule

Horizontal rules in the system's stroke scale. Weight carries hierarchy, because there is no grey.

- `weight`: `"hair"` 2px dashed (between list items), `"rule"` 3px (between sections), `"box"` 4px (under a chart, before a timeline), `"heavy"` 6px, `"bar"` 8px (under the masthead only), `"double"` 9px double (newspaper-style briefing).
- Never use a 1px rule: it prints faint and broken.
