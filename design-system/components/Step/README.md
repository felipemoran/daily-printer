# Step

A numbered instruction: a condensed display numeral, the step text, and an optional timer chip with a box to tick. For recipes and runbooks.

- Provide: `n` (1, 2, 3…), `children` (one or two sentences), `timer` ("12 min", "until golden").
- Intentional addition: not in the source explorations; added because recipes are a core print kind for this system.
- Keep each step to one action. Quantities go in the ingredient list, not the step.
