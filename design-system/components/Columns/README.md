# Columns

A vertical column chart with the value printed above each bar and the category below, on a 4px baseline.

- Provide: `data` (`{label, value, tone?}`), `height` (bar area, default 180), `width` (default 384).
- Up to 7 columns across 384 dots; column widths and heights are whole pixels. Give a `tone` (e.g. `tone-50`) to a projected or partial value.
