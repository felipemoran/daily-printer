# ReportTemplate

Weekly data report: Masthead (no rule) → 2-up StatTiles with the headline tile reversed → BarList comparing this week (solid) with last (tone) → Columns for daily volume.

- Feed it: period, 4 KPIs with deltas, 3–6 categories with two values, 7 daily values.
- Use ▲ ▼ in notes for direction; never rely on fill alone to say good or bad.
