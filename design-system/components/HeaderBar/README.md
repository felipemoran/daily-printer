# HeaderBar

A reversed bar across the top of an event print: what kind of print this is on the left, a time or status on the right.

- Provide: `left` (the print kind, uppercase), `right` (time, FINAL, a count). `outline` gives a hollow 4px version for low-ink prints.
- Text is `label` style: 700 with 3px tracking, so it holds open in white-on-black.
- Use for event-driven prints (ticket update, sales final, PR merged). Daily lists open with a `Masthead` instead.
